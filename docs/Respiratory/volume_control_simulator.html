Volume-control ventilator

Set tidal volume, inspiratory timing, and an optional inspiratory hold. The model computes peak and plateau pressure from resistance and compliance.

Model

Flow phase: V̇ = VT / Tflow
Hold phase: V̇ = 0
Expiration: dV/dt = −V / (R · C)

A hold reveals plateau pressure because the resistive pressure term falls to zero.
