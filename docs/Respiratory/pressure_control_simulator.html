Pressure-control ventilator

Set inspiratory pressure and timing. The model computes the decelerating flow and delivered tidal volume from resistance and compliance.

Model

Inspiration: dV/dt = (Pcontrol − V/C) / R
Expiration: dV/dt = −V / (R · C)

Volume is measured above the passive FRC volume associated with the set PEEP. If expiration is incomplete, residual volume creates intrinsic PEEP.
