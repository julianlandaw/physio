Historical development data

These exports and derived tables are retained as reference material from earlier
model development. They are not loaded by the website and may differ from the
current presets. Do not use them to update live browser presets directly.

The authoritative live registry is ../drug_registry.json. Run
python3 scripts/generate_presets.py from the repository root after editing it.
That command generates the shared browser data and the two CSVs in Pharmacology/.
